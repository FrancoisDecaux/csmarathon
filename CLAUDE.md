# Customer Success Marathon – démo jouable

Version test jouable du livre, publiée sur GitHub Pages : https://francoisdecaux.github.io/csmarathon/

- Tout le jeu est dans `index.html` (texte, règles par chapitre, images en base64). Pas d'autre fichier à charger.
- Le site est publié depuis la branche `gh-pages`. Après chaque modification :
  commit sur `main`, puis `git push origin main` et `git push origin main:gh-pages`.
  Le site se met à jour en 1 à 2 minutes.
- La page porte `noindex` : c'est une version de test, pas encore la version publique.

Répondre en français, en tutoyant.
